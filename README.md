## 🖥️ วิธีการเปิดใช้งานเว็บไซต์บนเครื่องเครื่องคอมพิวเตอร์ของคุณ (How to Run Locally)

เนื่องจากเว็บไซต์นี้เขียนขึ้นโดยมีระบบฝั่งเซิร์ฟเวอร์ (PHP) จึงจำเป็นต้องรันผ่าน PHP Web Server เท่านั้น (ไม่สามารถกดดับเบิลคลิกเปิดไฟล์ `.php` เฉย ๆ บนเบราว์เซอร์ได้)

สามารถเลือกวิธีเปิดใช้งานได้ตามความสะดวกของระบบคุณ ดังนี้:

### วิธีที่ 1: รันผ่าน PHP Built-in Server (แนะนำ - สะดวกและเร็วที่สุด)
หากในเครื่องคอมพิวเตอร์ของคุณมีการติดตั้ง PHP อยู่แล้ว (ตรวจสอบโดยใช้คำสั่ง `php -v` ใน terminal) ให้ทำตามขั้นตอนนี้:

1. เปิดโปรแกรม **Terminal**, **Command Prompt** หรือ **PowerShell**
2. นำทางเข้าไปยังโฟลเดอร์ของโปรเจกต์นี้:
   ```bash
   cd "ตำแหน่งที่เก็บโฟลเดอร์/CatCyberShop"
   ```
3. สั่งรันคำสั่ง PHP Server:
   ```bash
   php -S localhost:8000
   ```
4. เปิดเว็บเบราว์เซอร์ของคุณแล้วเข้าไปที่ลิงก์:
   👉 **[http://localhost:8000](http://localhost:8000)**

---

### วิธีที่ 2: รันผ่านโปรแกรม XAMPP / Laragon (ระบบจำลอง Server ยอดนิยม)
หากเครื่องของคุณใช้งานโปรแกรมจำลอง Apache Server เช่น XAMPP หรือ Laragon ให้ทำตามขั้นตอนนี้:

1. คัดลอกโฟลเดอร์ `CatCyberShop` ไปวางไว้ในโฟลเดอร์เครื่องเซิร์ฟเวอร์จำลอง:
   * **สำหรับ XAMPP:** นำไปวางที่โฟลเดอร์ `C:\xampp\htdocs\`
   * **สำหรับ Laragon:** นำไปวางที่โฟลเดอร์ `C:\laragon\www\`
2. เปิดโปรแกรม XAMPP หรือ Laragon ขึ้นมาแล้วกดปุ่ม **Start Apache**
3. เปิดเว็บเบราว์เซอร์ของคุณแล้วพิมพ์ URL ตามเส้นทางของโฟลเดอร์:
   👉 **`http://localhost/CatCyberShop/index.php`**

## 🌟 ฟังก์ชันหลักของระบบ (Features)
* **Home Page (`index.php`):** หน้าแรกต้อนรับของร้านค้า แสดงสโลแกนและไฮไลท์สินค้าเด่น
* **Products Page (`products.php`):** แสดงรายการแมวสายพันธุ์ต่าง ๆ และสเกลราคาโปรแกรม พร้อมเครื่องคำนวณงบประมาณแบบสดตามสเปกที่ผู้ใช้กดเลือกประกอบความต้องการลงในตะกร้าได้
* **Creator Page (`creator.php`):** หน้าข้อมูลส่วนตัวของผู้จัดจัดทำสไตล์การ์ดข้อมูลประวัตินักพัฒนาสุดล้ำ
* **Cart & Invoice (`cart.php`):** หน้าตรวจสอบสินค้าในตะกร้า, คิดคำนวณราคารวม, หักภาษีมูลค่าเพิ่ม (VAT 7%) พร้อมการจำลองระบบสั่งซื้อเพื่อออกเป็นใบเสร็จรับเงินที่สามารถสั่งพิมพ์ได้
