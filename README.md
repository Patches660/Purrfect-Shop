## 🌟 ฟังก์ชันเด่นของระบบ (Key Features)

### 1. 🐱 หน้าร้านขายเฉพาะน้องแมวสายพันธุ์แท้ 100%
* รวม 32 สายพันธุ์ยอดนิยม (British Shorthair, Persian, Sphynx, Siamese, Maine Coon, Ragdoll, Bengal, Scottish Fold, Munchkin, Russian Blue ฯลฯ)
* ข้อมูลละเอียดครบครัน: รูปภาพคมชัด, ช่วงอายุ, เพศ, ลักษณะขน, ข้อมูลวัคซีน, ใบเพ็ดดีกรี และจุดเด่นประจำสายพันธุ์
* ช่องค้นหาแบบสด (Live Instant Search) พร้อมการกรองหมวดหมู่และจัดเรียงราคา

### 2. 🧠 ระบบแนะนำสายพันธุ์อัจฉริยะ (Smart Cat Matcher)
* แบบทดสอบ 3 คำถาม (พื้นที่อยู่อาศัย, ไลฟ์สไตล์นิสัย, เวลาดูแลขน)
* ประมวลผลและจับคู่สายพันธุ์ที่เหมาะสมที่สุดพร้อมแสดงเปอร์เซ็นต์ความเข้ากันได้ (%)

### 3. 🛡️ ระบบสมัครสมาชิกตามมาตรฐาน PDPA
* หน้าสมัครสมาชิก (`register.php`) และเข้าสู่ระบบ (`login.php`)
* กล่องให้ความยินยอม (Consent Checkboxes) ครบถ้วนตามกฎหมาย PDPA (Email Consent, Phone/SMS Consent, Terms & Privacy Policy)
* **สิทธิพิเศษสมาชิก:** รับส่วนลดทันที 5% ทุกยอดการสั่งซื้อ

### 4. 🛒 ระบบตะกร้าและสั่งซื้อแบบเรียลไทม์ (`cart.php`)
* คำนวณยอดรวมสินค้า, หักส่วนลดสมาชิก VIP อัตโนมัติ, คิดภาษีมูลค่าเพิ่ม (VAT 7%)
* เลือกระบบชำระเงินได้หลากหลาย (โอนผ่านธนาคาร, PromptPay QR Code, บัตรเครดิต, หรือ Cash on Delivery)
* บันทึกข้อมูลคำสั่งซื้อลง JSON และสั่งส่งอีเมลยืนยันคำสั่งซื้ออัตโนมัติ

## 📧 สถาปัตยกรรมระบบอีเมลอัตโนมัติ (Email System Architecture)

ระบบ Purrfect Shop พัฒนาตัวส่งอีเมล **Pure-PHP REST API Mailer** (`EmailJsMailer`) โดยไม่ต้องพึ่งพา Composer เพื่อเชื่อมต่อกับ **EmailJS REST API v1.0** และรองรับ **Multi-Account** เพื่อขยายขีดจำกัดจำนวน Template:

```
                  ┌──────────────────────────────────────────────┐
                  │          Purrfect Mail Dispatcher            │
                  │              (sendActualEmail)               │
                  └──────────────────────┬───────────────────────┘
                                         │
        ┌────────────────────────────────┼────────────────────────────────┐
        │                                │                                │
        ▼                                ▼                                ▼
┌───────────────────────┐ ┌──────────────────────────┐ ┌──────────────────────────────────┐
│  Template 1 (VIP)     │ │  Template 2 (Newsletter) │ │  Template 3 (Order Confirmation) │
│  "template_xt7cq3g"   │ │  "template_y8wnrlt"      │ │  "template_pt8dolh"              │
│  สไตล์ Midnight Gold  │ │  สไตล์ Fresh Mint Gazette│ │  สไตล์ Warm Coral & Cream        │
│  (Account #1)         │ │  (Account #1)            │ │  (Account #2 - แยกบัญชี)         │
└───────────────────────┘ └──────────────────────────┘ └──────────────────────────────────┘
```

| แบบที่ | ชนิดอีเมล | สไตล์ดีไซน์ | รหัส Template ID | Trigger ที่ทำงาน |
|:---:|:---|:---|:---|:---|
| **1** | 👑 **ต้อนรับสมาชิก VIP** | Luxury Midnight Black & Gold | `template_xt7cq3g` | ส่งทันทีหลังลูกค้าสมัครสมาชิกสำเร็จ (`register.php`) แนบโค้ด `WELCOME15` |
| **2** | 📬 **รับข่าวสารแมวรายสัปดาห์** | Nature Fresh Mint & Cream | `template_y8wnrlt` | ส่งทันทีเมื่อกรอกอีเมลรับข่าวสาร (`subscribe.php`) แนบโค้ด `CATNEWS10` |
| **3** | 🛒 **ใบยืนยันคำสั่งซื้อ + รูปสินค้า** | Warm Coral & Cream | `template_pt8dolh` | ส่งทันทีหลัง Checkout สำเร็จ (`cart.php`) **แสดงรูปสินค้าน้องแมว**, ตารางราคา, VAT, ยอดสุทธิ และที่อยู่จัดส่ง |

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)

* **Backend:** Pure PHP 8.x (No Composer Dependencies required)
* **Frontend:** HTML5, CSS3 Modern Flexbox/Grid, Vanilla JavaScript (ES6+)
* **Database & Storage:** Flat-File JSON Storage (`data_users.json`, `data_orders.json`, `data_emailjs.json`, `data_newsletters.json`, `data_mail_outbox.json`)
* **Email Service:** EmailJS REST API v1.0 Client + Fallback SMTP Mailer (PHPMailer-compatible socket driver)
* **Fonts & Icons:** Prompt, Sukhumvit Set, Apple System Font Stack, Native Emoji

## 🚀 วิธีติดตั้งและรันในเครื่อง (Local Setup Guide)

1. **Clone โครงการจาก GitHub:**
   ```bash
   git clone https://github.com/Patches660/Purrfect-Shop-Files.git
   cd Purrfect-Shop-Files
   ```

2. **รันเซิร์ฟเวอร์ PHP Built-in Server:**
   ```bash
   php -S localhost:8000
   ```

3. **เปิดใช้งานบนเว็บเบราว์เซอร์:**
   * หน้าร้านค้า: [http://localhost:8000](http://localhost:8000)
   * หน้าทดสอบระบบอีเมล (Admin EmailJS Mockup): [http://localhost:8000/welcome_sales_mockup.php?view=emailjs](http://localhost:8000/welcome_sales_mockup.php?view=emailjs)
